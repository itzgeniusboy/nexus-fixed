# Master Agent implementation progress

The private fork now contains the Master task lifecycle, resumable `run()` entrypoint, checkpoint/resume state, dependency-aware dispatch, explicit blocked-worker semantics, persisted worker evidence, typed capability-aware workers, safe public browser inspection, bounded allowlisted project checks, read-only Git inspection, Termux/PC profile detection, provider/key routing hardening, fast queue acknowledgements, Enter submission fallback, exact image-fixture repair, and compact TUI Master/provider/model indicators.

The worker layer deliberately does not run arbitrary shell strings. Web and Android project checks are generated from detected project metadata, parsed against an allowlist, executed with fixed argument arrays, sequentially, with cancellation, 120-second timeouts, and capped output. Android `connectedCheck` is skipped unless `adb get-state` confirms a connected device, while Gradle unit/build checks remain available when the project wrapper exists. Git defaults to fixed-argument read-only status inspection, and the GitHub adapter uses only `gh repo view --json nameWithOwner,defaultBranchRef,url`; authentication, push, pull, issue, and pull-request mutations are not performed by these workers. Login, upload, personal data, CAPTCHA/2FA, external submissions, commit/push/PR, and other destructive actions remain approval-gated.

The legacy SessionPrompt regressions now pin their test sessions to the local `test/test-model`, so they no longer inherit an unrelated external default route. The normal prompt, static local-provider, and shell-to-loop tests pass; generic Runner ShellThenRun tests also pass. Full workspace typecheck remains constrained by sandbox memory, so focused formatting, lint, and regression suites are the reliable validation path here.
