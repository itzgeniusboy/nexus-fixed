# Master Agent implementation progress

The private fork now contains the Master task lifecycle, checkpoint/resume state, typed capability-aware workers, safe public browser inspection, bounded allowlisted project checks, read-only Git inspection, Termux/PC profile detection, provider/key routing hardening, fast queue acknowledgements, Enter submission fallback, exact image-fixture repair, and compact TUI Master/provider/model indicators.

The worker layer deliberately does not run arbitrary shell strings. Web and Android project checks are generated from detected project metadata, parsed against an allowlist, executed with fixed argument arrays, sequentially, with cancellation, 120-second timeouts, and capped output. Android `connectedCheck` is skipped unless `adb get-state` confirms a connected device, while Gradle unit/build checks remain available when the project wrapper exists. Git defaults to fixed-argument read-only status inspection, and the GitHub adapter uses only `gh repo view --json nameWithOwner,defaultBranchRef,url`; authentication, push, pull, issue, and pull-request mutations are not performed by these workers. Login, upload, personal data, CAPTCHA/2FA, external submissions, commit/push/PR, and other destructive actions remain approval-gated.

The legacy SessionPrompt tests that expect the fake local provider to answer currently inherit an external configured default route (`opencode/grok-code-fast-1`) instead of the test provider and fail with `Model grok-code-fast-1 is not supported` before contacting the fake server. The shell-to-loop test is therefore not a Runner concurrency failure: generic Runner ShellThenRun tests pass. Temporary diagnostics were removed, and no test fixture changes were retained. Full workspace typecheck remains constrained by sandbox memory; focused formatting, lint, and tests are the reliable validation path here.
